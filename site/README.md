# BeamTube website

The project site, live at https://beamtube.johankrs.com/: plain HTML, CSS and JavaScript, with no
build step and nothing to install on the server. All paths are relative, so it works from any folder
or subdomain.

## Publishing

Copy everything in this folder (except this README, if you like) to the web server. That's it.

## Editing

- **Text:** the English text is in `index.html`. The Portuguese and Spanish versions are in
  `assets/i18n.js`, under the same keys as the `data-i18n` attributes. When you change an English
  text, change both translations too.
- **Language:** the page picks `?lang=pt` / `?lang=es` from the address, then the visitor's last
  choice, then the browser's language, and falls back to English.
- **Brand art, fonts and screenshots** are generated by `tools/make_site_assets.py` from the app's
  own icon drawing (`tools/make_icons.py`), its Outfit font and `docs/screenshots/`. Run it again
  after changing any of those.
- **The address** appears only in the `<head>` of `index.html` (the canonical link, the language
  links and the `og:` tags for link previews, which need a full address). If the site moves, change
  it there. The preview picture is `og-image.png`, also from `tools/make_site_assets.py`.
- The site is dark only, on purpose.
