- **TV player: the arrows work right away.** With the controls hidden, left and right now move along the timeline at once (10 seconds per press, with the preview; OK jumps there, Back cancels). Up opens the controls on the channel name, and down on play/pause. Until now, any arrow just brought up the controls on play/pause, so left and right only moved between the buttons.
- **One press, one tab.** Right after the TV was turned on, a single press on the tabs could skip two or three of them, all the way to Search: a freshly woken remote can send the key release late, and the TV takes it as a held arrow. On the tabs and the side menu, each press now moves one tab. Holding an arrow on the videos still scrolls.
- **Recommended and Explore open instantly.** Recommended loads in the background and, if you get there before the new list does, shows the one from last time. What you are looking at never jumps: the rows on screen stay put and the new list comes in right below them, and when you leave the tab and come back, only the new list is there. The saved list starts with the videos you hadn't seen yet, so it doesn't open looking the same as last time. Subscriptions still updates as soon as new videos arrive. Explore now loads in the background right after Subscriptions, like Recommended, and opens with a set of channels picked the time before, so it shows up at once and is still different on every visit. OK on the tab still picks new channels.
- **Lighter loading in the background.** The other tabs now load one at a time after Subscriptions, instead of all at once, and only the thumbnails of each tab's first screen are fetched ahead. The rest loads as you scroll, so the app stays responsive while it starts.
